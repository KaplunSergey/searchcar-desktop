# Зафиксированные решения SearchCar Desktop

Дата фиксации: 2 августа 2026 года.

Этот документ хранит уже согласованные продуктовые и архитектурные решения.
Они считаются исходными условиями плана и меняются только отдельным решением с
описанием причины и влияния на сроки.

## Продукт и распространение

| Решение | Принятое значение |
| --- | --- |
| Название продукта | SearchCar Desktop |
| Имя локального репозитория | `searchcar-desktop` |
| Исходный web-проект | Остаётся без изменений в отдельном репозитории |
| Формат поставки | Установщик `.exe` для Windows и `.dmg` для macOS |
| Поддерживаемые системы первой версии | Windows 10/11 x64; macOS 13+ Apple Silicon |
| Intel Mac | Не поддерживается в первой версии |
| Docker у клиента | Не требуется |
| Запуск приложения | Только вручную; автозапуск вместе с ОС исключён из первой версии |
| Поиск и обновление объявлений | Ручные и фоновые автоматические запуски по настраиваемому расписанию |
| Фоновый режим | При активном scheduler закрытие окна скрывает приложение в tray; `Выйти` полностью завершает процессы |
| Локальная рабочая область | Desktop не показывает аккаунт, логин, пароль или logout. Один скрытый `SearchCar` user существует только как технический владелец локальных данных; код активации вводится один раз на новом устройстве. |
| Сон во время поиска | Поиск безопасно прерывается, уже записанные результаты остаются в частичном отчёте истории, браузер закрывается |
| Пропущенный запуск | Если после пробуждения/следующего запуска прошло не меньше интервала от последнего полного обновления, один catch-up scan ставится в очередь сразу; параллельные scans запрещены |
| Ручное `Обновить проекты` | После завершения фактически начавшегося run: `next_run_at = finished_at + текущий интервал`; ожидающий automatic run объединяется с ручным; обновление одного авто расписание не сдвигает |
| Первый релиз | Бесплатная неподписанная пилотная сборка с инструкциями по системным предупреждениям |
| Платные подписи ОС | Отложены до коммерческого распространения |

## Локальная архитектура

| Область | Решение |
| --- | --- |
| Desktop-оболочка | Tauri 2 |
| Интерфейс | Переиспользование текущего React-интерфейса |
| Desktop frontend build | Обычный Vite SPA без Next/Vinext server runtime |
| Backend | FastAPI/worker как скомпилированный `searchcar-core` sidecar |
| Защита Python-кода | Nuitka для backend, parser, scanner и worker |
| Лицензионная проверка клиента | Нативный слой Rust/Tauri плюс повторная проверка в backend |
| База данных клиента | SQLite вместо PostgreSQL |
| Браузер парсера | Закреплённая версия Playwright Chromium, включённая в установщик |
| Изображения и скриншоты | Локальные файлы с относительными путями в БД |
| Шифрование БД и изображений | Не требуется |
| Полная anti-tamper система | Не требуется; обязательны подписи лицензий и обновлений |
| Локальные пользователи | В production first-run создаётся один рабочий профиль автоматически после активации; старые локальные пользователи мигрируются без потери данных |

## Лицензирование

| Правило | Принятое значение |
| --- | --- |
| Лицензионный сервер | Cloudflare Worker + D1 на бесплатном тарифе |
| Админка лицензий | Отдельное web-приложение, доступное только владельцу |
| Клиентский вход | Парольный cloud-аккаунт не создаётся: первый запуск активируется одноразовым кодом, далее доступ подтверждает ключ устройства |
| Центральная карточка клиента | Контакт, лицензия, устройство, история и включённые источники хранятся только в Cloudflare; это не синхронизация рабочих данных |
| Бесплатный период | 30 суток с первой успешной онлайн-активации |
| Привязка | Одна лицензия — один компьютер |
| Проверка | При запуске и далее не реже одного раза в 24 часа, пока приложение открыто |
| Льготный период связи | Один дополнительный день при недоступности сервера |
| Окончание подписки | После реальной даты окончания поиск блокируется; льготный день связи не продлевает подписку |
| Предупреждение | Верхняя строка за сутки до окончания и в последний день |
| После окончания | Доступны просмотр, комментарии, избранное, рейтинги, экспорт, backup и ввод ключа |
| Что блокируется | Ручной/автоматический поиск, обновление проектов и индивидуальное обновление авто |
| Сроки ключей | 1, 3, 6, 12 календарных месяцев и бессрочный |
| Продление активной лицензии | Прибавляется к существующей дате окончания |
| Продление истёкшей лицензии | Начинается от текущего серверного времени |
| Повторное использование ключа | Запрещено; ключ одноразовый и хранится на сервере только как хеш |
| Бессрочная лицензия | Не истекает, но продолжает ежедневную проверку сервера и привязку к устройству |
| Отзыв лицензии | Обычной функции отзыва нет; разрешена только смена устройства владельцем |
| Виртуальные машины | Не входят в официально поддерживаемый сценарий первой версии |
| Доступ к сайтам-источникам | Каждый источник имеет постоянный ключ; владелец включает его для лицензии в центральной админке, а подписанный lease запрещает scan выключенного источника |
| Облачная синхронизация | Не входит в первый запуск и отложена отдельной фазой; проекты, автомобили и изображения остаются локальными |

## Перенос устройства и данных

| Область | Решение |
| --- | --- |
| Перенос лицензии | Подтверждается владельцем через админку |
| Код переноса | Одноразовый короткоживущий запрос, созданный новым устройством |
| Старое устройство | Перестаёт получать разрешения; может работать до окончания ранее выданного lease |
| Срок лицензии после переноса | Не меняется |
| Счётчик активаций | Увеличивается при каждом подтверждённом переносе |
| Формат данных | Один файл `*.searchcar-backup` |
| Содержимое backup | SQLite, изображения, скриншоты, manifest, версия схемы и checksums |
| Лицензия в backup | Никогда не включается |
| Первая версия импорта | Полная замена локальных данных, без merge двух баз |
| Кроссплатформенный перенос | Windows ↔ macOS поддерживается |

## Обновления

| Область | Решение |
| --- | --- |
| Исходный код | Приватный репозиторий |
| Бинарные релизы | Отдельный releases-only репозиторий без исходного кода |
| Стоимость хостинга обновлений | Бесплатный GitHub Releases на первом этапе |
| Текущая версия | Всегда отображается в `Настройки → О приложении` и диагностике |
| Проверка обновлений | При запуске и периодически открывается `latest.json` из releases-only репозитория |
| Доступное обновление | Появляется кнопка `Обновить до vX.Y.Z` с release notes |
| Установка обновления | Только после нажатия: backup → download → signature check → install → restart → migrations |
| Защита обновлений | Обязательная подпись Tauri; приватный ключ не хранится в приложении |
| Сведения в админке | Текущая версия клиента и последняя проверка |

## Диагностика и поддержка

| Область | Решение |
| --- | --- |
| Основной подход | Структурированные локальные rotating logs без обязательной telemetry |
| Срок хранения | До 7 дней и до 50 МБ на установку |
| Создание отчёта | `Настройки → Диагностика → Создать отчёт для поддержки` |
| Период отчёта | Последние 24 часа по умолчанию или 7 дней |
| Место сохранения | Выбирает пользователь стандартным диалогом ОС |
| Формат | Проверенный ZIP с manifest, очищенными логами, health snapshot и support ID |
| Передача | Только вручную пользователем; автоматическая отправка отсутствует |
| Запрещённое содержимое | Секреты, пароли, cookies, коды, private keys, SQLite, изображения, комментарии и контакты |

## Минимальные сведения лицензионной админки

- пользователь;
- идентификатор лицензии;
- статус;
- привязанное устройство;
- дата первой активации;
- последняя проверка;
- дата окончания;
- история продлений;
- версия приложения;
- количество активаций и переносов.

## Граница обещаемой защиты

Цель — исключить доступ к исходным Python-файлам, обычное копирование логики,
повторное применение ключей, продление подписки переводом часов и клонирование
лицензии через backup. Нельзя обещать абсолютную защиту от специалиста с
административным доступом, дизассемблером и возможностью патчить нативный
бинарник. Абсолютная защита потребовала бы переноса ценной логики на сервер или
аппаратного лицензионного ключа, что не входит в текущий объём.
