# UI аукционов: покрытие состояний v4

08.10.2026 · ветка `codex/multisource-auctions` · дизайн для согласования.

[Интерактивный макет](mockups/auction-cards-v4.html) использует один
`cardHTML` для IAA/Copart, независимо от Encar. Цвета, шрифты и геометрия
ориентированы на существующий SearchCar; новые зависимости не добавлены.
Нижнего footer с ACV/площадкой/избранным и раскрывающихся деталей нет.
Макет не читает сайты/базу, не запускает поиск и ничего не публикует.
Размещение той же карточки в текущей оболочке — [интеграционный макет](AUCTION_APP_INTEGRATION_MOCKUP.md).
Время зафиксировано: 08.10.2026 12:37 Europe/Warsaw. Фото — локальная заглушка,
ссылки явно ведут на поиски, не на демонстрационные лоты.

## Как посмотреть

Открыть через локальный HTTP-сервер (ES-модуль, не `file://`):

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory docs/mockups
```

Если сервер уже запущен на этом порту, повторно не запускать.
Адрес: `http://127.0.0.1:8769/auction-cards-v4.html`.

«Пример списка» показывает три карточки выбранного сайта. «Состояния карточки»
и панель «Проверка состояний» позволяют сочетать признаки. «Каталог значений»
показывает весь наблюдавшийся словарь. RU/UK переключаются справа сверху.
Сайт переключается отдельно: общей смешанной подборки нет.

## Независимые признаки

| Ось | Покрытие | Отображение |
| --- | --- | --- |
| Запуск / подготовка | Run & Drive, Starts, Stationary, Engine Start, Enhanced, пусто/raw | Отдельная метка; Enhanced нейтрален, не доказательство запуска |
| Одометр | Actual, Not Actual, Inoperable Digital Dash, Exceeds Mechanical Limits, пусто/raw; Exempt справочно | Число/единица + достоверность; 0 сохранён, неизвестное не заменяется нулём; км только для Actual mi |
| Повреждения | 35 IAA + 18 Copart из аудита; primary/secondary, пусто/raw | Выделенная подпись + оригинал; без выдуманной шкалы тяжести |
| Ключи | Есть / нет / неизвестно | Пустое поле не означает «нет»; отрицание IAA не выдаётся за найденное значение |
| Подушки | Deployed / Intact / Missing / None / пусто/raw | IAA-поле, в Copart не переносится |
| Документы | Наблюдавшиеся категории + Title Not Yet Available + произвольный raw-код | Отдельно от механического состояния; без юридической интерпретации |
| Условия продажи | Pure Sale / On Approval / Minimum Bid / On Reserve / If Bids | Справочные варианты, не «Продано» и не этап аукциона |
| Другие признаки | Loss Type IAA; Public/Offsite/Lane TBD, Fleet/Rental, редкие Copart-флаги | Независимые нейтральные метки; Green/Red Light не толкуются как исправность |
| Действие источника | Pre-Bid, Join Auction, Timed/BID NOW, Buy Now, Bid now и другие найденные подписи | Сохраняется raw-метка, не кнопка ставки и не вывод о live |
| Суммы | Текущая ставка / Buy It Now / нет данных | Назначение, USD и время снимка; отсутствие не заменяется нулём |
| Фото / ссылка | Фото недоступно; ссылка отсутствует/небезопасна | Заглушка/неактивная подпись; HTTPS допустимых источников, raw-текст экранирован |

Наблюдения — [аудит пагинации](AUCTION_PAGINATION_AUDIT_2026-10-07.md),
а не обещание полного каталога будущих состояний сайтов. Новые значения
отображаются оригинальным текстом. Справочные и проектные варианты помечены
отдельно; комбинации в макете не являются реальными объявлениями.
Actual и суммы для IAA — проектные примеры; гостевая текущая ставка IAA
не подтверждена исследованием. По умолчанию обычное показание IAA не получает
ярлык Actual и пересчёт в км.

## Расписание и этапы — 16 сценариев

| Случай | UI / граница |
| --- | --- |
| Точная дата будущего начала | Локальные дата/время + «Через …»; компактно «Сегодня · 8 октября» |
| Явный сигнал live | «Аукцион идёт»; дата расписания не выдаётся за точное время выхода лота |
| Плановое время наступило | Предложение: «Время по расписанию наступило», этап не подтверждён; не LIVE/SOLD |
| Перенос | Отдельный статус и новая дата; проектный пример |
| IAA US Timed с неподтверждённым смыслом времени | «Время события · Timed», без отсчёта до начала/окончания |
| Подтверждённое окончание Timed | «До окончания …»; проектный сценарий, не подтверждение US-семантики |
| Только дата | Дата без отсчёта; локальный день требует проверки |
| Неизвестный пояс | Исходное время/предупреждение, без выдуманного отсчёта |
| Future / Upcoming lot / Auction Not Assigned | Три отдельных примера; новые бездатные лоты не добавляются в активный проект |
| Дата исчезла у сохранённого лота | Отдельное предупреждение; политика хранения ещё не согласована |
| Завершение / отмена | Только подтверждённый сигнал; два проектных примера |
| Исчезновение | История после полного успешного поиска с прежними условиями; не «Продано» |
| Неизвестный этап | Raw fallback без придуманных времени/результата |

Бездатные/закрытые примеры доступны в лаборатории, не выданы за активные
автомобили проекта. Для Timed US отбор «Сегодня» и Telegram остаются нерешёнными.

Уточнение подписи даты: текущий год в основной строке не повторяем, другой
год сохраняем без суффикса «г.». Полная локальная дата с годом доступна через
`title` при наведении. «Сегодня» и сравнение года вычисляются в том же поясе,
что время аукциона, а не по UTC.

## Состояния списка — 7 сценариев

Успешный поиск; загрузка со skeleton; нет аукционов сегодня; неполный поиск
(включая ограничение Copart 1000+); ошибка со старым снимком; отмена поиска; недоступный
публичный источник. Ошибка/частичный охват не превращаются в пустую выдачу
или основание убрать старые лоты. При ошибке макет не показывает старую ставку
и live как актуальные: указывает время последнего успешного снимка.

## Проверки

- RED → GREEN для правил отображения; первое падение инфраструктуры экспорта
  ES-модуля было разобрано отдельно и не засчитано как поведенческий RED.
- 10 Node-тестов, включая все 64 сочетания 16 сценариев × 2 сайта × 2 языка,
  словарь 35/18, unknown/zero, безопасный raw и ссылки, отсутствие footer/details.
- Дополнительный RED выявил RangeError на неизвестном поясе и пропуск метки
  действия; причины исправлены в представлении, проверки не ослаблены.
- В браузере: 32 перехода этапов (два сайта), 14 переходов состояний поиска
  (два языка), неизвестные повреждения/одометр, None для подушек.
- Проверены 1280/600/360: нет горизонтального переполнения.
- Каталоги в браузере совпадают с 35/18; клавиатурный Tab переводит фокус
  с переключателя IAA на язык, консоль без ошибок/предупреждений.
- Компактная дата: RED на старой длинной подписи → GREEN; RU/UK при ширине
  1280/936/600/360 — строка 22,5 px, без переполнения. На исходном IAA-примере
  карточка уменьшилась с 372,6 до 350,1 px, ширина блока не увеличивалась.
- Это проверки браузерного макета, не запуск Windows/macOS-приложения.

```sh
node --test docs/mockups/auction-card-ui.test.cjs
```

Согласование макета, остальные экраны MSA-03 и доступ источников MSA-01
не закрыты. Код приложения, адаптеры, миграции и данные пользователей не менялись.
