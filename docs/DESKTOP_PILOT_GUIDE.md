# SearchCar Desktop — инструкция для пилотного пользователя

Эта инструкция рассчитана на человека без навыков разработки. Для работы не
нужны терминал, Docker, Python или отдельный браузер для поиска.

## 1. Установка и первый запуск

1. Скачайте установщик, который прислал владелец SearchCar.
2. **Windows:** запустите `SearchCar Desktop … setup.exe` и завершите мастер.
   Если SmartScreen предупредит о неизвестном приложении пилотной версии,
   подтвердите запуск только если файл получен от владельца.
3. **macOS:** перенесите `SearchCar Desktop.app` в «Программы». При первом
   запуске macOS может потребовать открыть приложение через контекстное меню
   «Открыть»: пилотная сборка пока не имеет коммерческой подписи Apple.
4. Подождите окно «Запускаем SearchCar». Оно проверяет локальные данные и
   запускает встроенный сервис. Не закрывайте его до появления главного окна.

## 2. Активация

1. Откройте `Настройки`.
2. В поле «Код активации» вставьте одноразовый код, полученный от владельца.
3. Нажмите «Активировать».

Лицензия закрепляется за одним компьютером. Не передавайте код другим людям.
Если нужен новый компьютер, используйте перенос устройства, а не повторное
использование старого кода.

## 3. Первый проект и поиск

1. Нажмите `Проекты` → `Создать проект`.
2. Введите понятное название и вставьте ссылку на выдачу Encar.
3. Для нового проекта по умолчанию выбраны «Все страницы».
4. Сохраните проект и нажмите «Обновить».

Первый успешный поиск всегда точный и проходит все страницы, поэтому может
занять заметно больше времени. Следующие обновления используют выбранный
режим проекта. Не закрывайте приложение во время активного поиска: при выходе
оно предупредит и сохранит уже обработанную часть в истории.

## 4. Автоматические обновления

В `Настройки` выберите интервал и проекты, затем нажмите «Сохранить
планировщик». Если компьютер был в сне дольше выбранного интервала, SearchCar
выполнит один пропущенный поиск после пробуждения. Приостановка отключает
только автоматические обновления — ручная кнопка «Обновить» остаётся доступна.

## 5. Резервная копия и перенос

Перед сменой компьютера в `Настройки` → «Данные настольного приложения»
нажмите «Создать резервную копию» и сохраните файл в надёжное место.

На новом компьютере:

1. Установите SearchCar.
2. Восстановите резервную копию в настройках.
3. Запросите перенос лицензии и передайте код владельцу.
4. После подтверждения владельца нажмите «Завершить перенос».

Проекты и история переносятся резервной копией. Лицензия в неё не входит и
переносится отдельно.

## 6. Если что-то не работает

1. Откройте `Настройки` → «Диагностика».
2. Для свежей проблемы выберите «Последний час», иначе — 24 часа, 3 или 7
   дней.
3. Нажмите «Создать отчёт для поддержки».
4. Проверьте строку состава: архив содержит только `manifest.json` и
   `logs.jsonl`; в нём нет базы, машин, изображений или лицензии.
5. Нажмите «Сохранить отчёт». Если системный выбор папки не открылся, ZIP
   будет скачан приложением. Кнопка «Открыть папку» показывает готовый архив
   в Finder или Проводнике.
6. Отправьте владельцу ZIP и код отчёта, который показан в приложении.

Отчёт никуда не отправляется автоматически. Не прикладывайте к обращению
скриншоты с личными данными, если владелец их отдельно не запросил.

## 7. Обновление приложения

SearchCar проверяет обновления при запуске и примерно раз в шесть часов. При
выходе новой версии приложение покажет предложение установить её. Перед
установкой завершите активный поиск или отмените его; SearchCar создаст
резервную копию перед обновлением.

Если обновление не устанавливается, продолжайте пользоваться текущей версией
и отправьте диагностический отчёт владельцу.
